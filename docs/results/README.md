# Selected validation summaries

These are small aggregate outputs from the conditional Pal5 experiments described
in [DENSE_TEST_RESULTS.md](../DENSE_TEST_RESULTS.md). They contain no source-level
Gaia catalogue, individual simulated trajectories or credentials.

- `dense_noise.csv`: independent-seed template noise at different spatial scales.
- `nested_thinning.csv`: correlated nested 2k/4k/8k comparisons; not independent runs.
- `age_preflight.csv`: sparse prescribed-history lookback-window count preflight.
- `enlarged_calibration.json`: fixed-template calibration follow-up and fresh holdout.

The corresponding figures are in `../figures/`. Full simulation inputs, checksums,
logs and original results remain in the local ignored `outputs/` directory.
