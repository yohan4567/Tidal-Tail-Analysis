# 實驗流程檢查與修正（2026-10-31）

## 判定

目前能產出以真實 Gaia 資料與明示物理模型為條件的流失率分布，
**不能宣稱已量得全質量範圍、模型獨立或已驗證的真實總流失率**。
六份已完成的 Pal 5／NGC 288 δ 後驗都仍有此限制。
這不是宣稱它們一定錯誤，而是現有證據不能排除重要人口與觀測系統誤差。

本次實際檢查六份後驗所用的 30 份人口表：CSV 校驗與單位存活星質量正規化
皆通過，合成資料標記為 0 份；六份結果皆檢出量測區間外的 MF 外推。
修正後全套 98 項軟體測試通過。這些是輸入／數值與回歸檢查，不是物理驗證。

| 階段 | 檢查所得 | 狀態／修正 |
|---|---|---|
| Gaia 原始場與遮罩 | 有來源、實際視野、選星 cutflow 與檔案雜湊；Pal 5 實際場為 5° | 不擴稱目錄或模擬範圍就是觀測範圍；仍須獨立驗證尾巴選擇 |
| 原始整數計數 | 空間格統計，再按互斥像素加總；Poisson 模型使用整數觀測值 | 不將平滑圖像素當成獨立計數 |
| 完整率／誤差／品質 | 使用個別星團的母樣本、選擇函數與誤差取樣 | 有真實來源不等於對逃逸人口適用；校正轉移與背景形狀仍須檢查 |
| 祖星團全域 MF | 有量測、斜率定義與量測範圍 | 它不是逃逸 MF；既有 δ 情境仍只作條件式敏感度分析 |
| Pal 5 尾巴 MF | 已新增直接文獻人口，傳播所報形式誤差 | 南北分開；整視野／歷史轉移與低質量外推明示，未宣稱消除所有人口誤差 |
| 人口質量正規化 | 每個所代表存活星族群為單位現今質量；測試檢查質量守恆 | 未包括完整殘骸、等時線下限外人口；不能稱為所有逃逸質量 |
| 動力學質量歷史 | 採 M(t)=M_now+f R |t|；f=1、固定尺度與固定銀河勢為假設 | R 不只是自由振幅；動力學與人口換算尚未獨立約束 |
| 粒子與窗口 | 固定數值設定，三種子；短 T 取長 T 釋放子集且不重新正規化 | 程式有相容性／窗口測試，但正式粒子收斂與外尾檢查尚未完成 |
| likelihood／邊際化 | 對校正狀態平均原始 Poisson likelihood；積分背景、時間與人口 | 保留有限先驗支持與先驗敏感度；舊 q 不能直接當後驗 |
| 零訊號 | 舊的正 R 網格無法自行檢定尾巴是否存在 | 新版加入同遮罩、同背景先驗的背景-only 比較，不把正 R 當成偵測證據 |
| 後驗範圍 | NGC 288 低 R、Pal 5 高 T 有邊界問題 | 要擴界／加密才可檢查；目前區間仍受有限支持影響 |
| 回收與模型適用性 | 軟體測試存在，獨立模型失配回收與物理驗證未完成 | 不因所有單元測試通過就標記 physical validation passed |

## 本次程式修正

1. `tail_population.py` + `run_tail_study.py`：Pal 5 使用文獻尾巴 MF 重跑，
   沿用相容且不再寫入的動力學，模板與後驗存入新目錄。
   南／北文獻斜率各自轉移到整個擬合視野，是兩個條件式假設，
   不是對原文兩個測光視野做過空間匹配，也不任意相乘或等權平均。
2. `bayesian_grid.py`：新增背景-only 的積分 likelihood，
   並以有限軸先驗的正確積分正規化計算條件式 Bayes factor。
   它依賴背景模型、MF 與先驗支持，不等於校準後的顯著性或物理尾巴存在證明。
   若背景在有觀測星的像素為零，會標示背景支持問題，不自動宣稱確定偵測。
3. `audit_experiment.py`：讀取完成結果、保存摘要檔雜湊、檢查有限區間與人口／質量限制，
   將 `primary_total_absolute_rate_msun_myr` 保持為 null，避免把條件式結果誤標成全質量測量。
   該稽核不是新觀測或完整的獨立科學驗證。
4. 原結果保留，不以新方法重新命名。未重算的舊後驗不會自動得到新的零訊號比較。

## 仍不能只靠修改程式補上的部分

- 星團外的低質量恆星 MF、殘骸逃逸與動力學／人口質量轉換需要獨立資料或經驗證的模型。
- 用來擬合人口的同份 CMD，不能再當成獨立資料重複乘 likelihood。
- 外部 MF 若只涵蓋狹窄質量範圍，所報斜率誤差不能代表低質量外推誤差。
- 如資料只限制觀測質量範圍，應改報該範圍的逃逸量或可見星數；
  把目前全等時線率直接乘一個固定比例不是已驗證的替代測量，因動力學也耦合總質量。

其他星團的資料／多質量模型方案見 [逃逸人口策略](ESCAPING_POPULATION_STRATEGY_ZH.md)。
在觀測閉合以前，本專案仍是「有明示假設的模型推論」，不是不依賴模型的真值讀取器。

## 可重現檢查

```powershell
python -m unittest discover -q
python audit_experiment.py --root outputs/cluster_survey_29_v1 --out outputs/experiment_audit_v1
```

檢查報告放在 `outputs/experiment_audit_v1/AUDIT_ZH.md` 與 `audit.json`。
它只檢查已完成的結果，不會阻擋正在執行的條件式運算。

- [Koch et al. (2004)](https://arxiv.org/abs/astro-ph/0408208)：Pal 5 尾巴與內部 MF；單一冪次律近似限制。
- [Chen, Li & Gnedin (2025), §II.4／Appendix B](https://arxiv.org/html/2411.19899v2)：漏掉昏暗星的質量函數修正及敏感度。
- [Kruijssen (2009)](https://doi.org/10.1051/0004-6361/200913325)：質量相依逃逸與殘骸／分層模型。
- [Webb et al. (2017)](https://arxiv.org/abs/1707.06653)：徑向 MF 與多質量演化比較，不等於直接測得逃逸 MF。
